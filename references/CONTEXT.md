# 共享术语

**候选项目**：由入口发现但未完成证据核验的项目；不能计作已核验推荐。

**已核验项目**：真实官方仓库、当前观测和介绍依据均已读取；不代表代码已运行或质量有保证。

**热门**：明确时间窗口中的关注度信号；上榜、讨论与Star净变化分开记录。

**有趣**：对某种用途或体验有吸引力的编辑判断；不是可验证的客观排名。

**创新线索**：相较明确参照对象可解释的实现或用途差异；不等于已证明学术新颖性。

**贡献线索**：真实issue或维护者公开请求；未必空闲、可完成或欢迎外部认领。

**待复核贡献候选**：通过本次状态门槛、值得用户进一步检查的任务，不是“保证适合”。

**未发现认领**：在注明范围和时间内的观测性判断，不能简写为“确定无人认领”。

**建议性任务**：助手提出的改进想法；不能计作维护者需求或真实issue。

**原始证据**：源页面短摘录、官方API响应字段或明确记录的读取结果；带URL、时间与哈希。

**领域匹配**：任务涉及用户研究主题；不自动推出语言、框架或工程能力匹配。

**增量**：两次真实观测之间的变化，不自动等于过去24小时发生的变化。

**覆盖缺口**：计划来源/领域未访问、访问失败或未核验；不是零结果。

**持久记忆**：可查询的证据、观测、报告及明确反馈，不是无限增长的聊天历史。

**降级日报**：资料不足时仍交付真实的已核验部分、失败原因和下一次恢复点。
