# 开发种子集

当前文件记录真实候选、3 个项目的 9 条主张和2条issue判断。标签来源为 Agent 审阅，不是独立人工金标准；个人相关性尚未由用户标注，不计算准确率或效率提升。

后续按仓库/issue身份分组划分开发与留出集，并另保留时间留出。历史回放使用保存的实际观测与判定时间，不修改时间戳让证据变新。初始目标约10个项目、12条issue、30组主张—证据对，应在真实使用中扩充；不能将10个浅层候选等同于10个完成深读的评估样本。

正式比较至少包含简单规则、冻结的1.0.0和人工流程。报告推荐相关性、候选误判与覆盖、证据支持程度、人工耗时和资源用量。所有指标注明样本量，未知保留null。

公开种子包含来源URL、时间与摘要哈希索引。完整原始捕获保存在独立本地运行工作区；只克隆代码仓库不能离线重放这次真实采集。合成流程可由随包测试完整复现。
